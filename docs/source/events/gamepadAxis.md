Fires after vanilla input polling when a gamepad axis or slider changes. Includes joysticks enumerated by vanilla DirectInput and requires the game to initialize those devices. This observes raw state changes, including state resets when acquisition fails. It does not block game input.

```lua
--- @param e gamepadAxisEventData
local function gamepadAxisCallback(e)
end
event.register(tes3.event.gamepadAxis, gamepadAxisCallback)
```

!!! tip
	This event can be filtered based on the **`gamepad`** event data.

!!! tip
	An event can be claimed by setting `e.claim` to `true`, or by returning `false` from the callback. Claiming the event prevents any lower priority callbacks from being called.

## Event Data

* `axis` ([tes3.gamepadAxis](../references/gamepad-axiss.md)): *Read-only*. The zero-based axis ID. Compare against tes3.gamepadAxis constants.
* `gamepad` (integer): *Read-only*. The zero-based gamepad ID.
* `previousValue` (integer): *Read-only*. The value from the preceding input poll, in the same units as value.
* `value` (integer): *Read-only*. Raw absolute device-dependent axis value. No additional normalization or dead zone is applied.
