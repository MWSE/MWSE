Fires after vanilla input polling when a gamepad POV hat changes. Includes joysticks enumerated by vanilla DirectInput and requires the game to initialize those devices. This observes raw state changes, including state resets when acquisition fails. It does not block game input.

```lua
--- @param e gamepadPovEventData
local function gamepadPovCallback(e)
end
event.register(tes3.event.gamepadPov, gamepadPovCallback)
```

!!! tip
	This event can be filtered based on the **`gamepad`** event data.

!!! tip
	An event can be claimed by setting `e.claim` to `true`, or by returning `false` from the callback. Claiming the event prevents any lower priority callbacks from being called.

## Event Data

* `gamepad` (integer): *Read-only*. The zero-based gamepad ID.
* `isCentered` (boolean): *Read-only*. True when the POV hat is centered (no direction is pressed).
* `pov` (integer): *Read-only*. The zero-based POV hat ID, from 0 to 3.
* `previousValue` (number): *Read-only*. The clockwise angle in degrees from the preceding input poll. When wasCentered is true, this is 0 and does not represent a direction.
* `value` (number): *Read-only*. Clockwise angle in degrees, from 0 up to but not including 360. North is 0, east is 90, south is 180, and west is 270. When isCentered is true, this is 0 and does not represent a direction.
* `wasCentered` (boolean): *Read-only*. True when the POV hat was centered in the preceding input poll.
