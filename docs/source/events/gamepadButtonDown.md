Fires after vanilla input polling when a gamepad button is pressed. Includes joysticks enumerated by vanilla DirectInput and requires the game to initialize those devices. This observes raw state changes, including state resets when acquisition fails. It does not block game input.

```lua
--- @param e gamepadButtonDownEventData
local function gamepadButtonDownCallback(e)
end
event.register(tes3.event.gamepadButtonDown, gamepadButtonDownCallback)
```

!!! tip
	This event can be filtered based on the **`gamepad`** event data.

!!! tip
	An event can be claimed by setting `e.claim` to `true`, or by returning `false` from the callback. Claiming the event prevents any lower priority callbacks from being called.

## Event Data

* `button` (integer): *Read-only*. The zero-based DirectInput button ID, from 0 to 31. Device mappings vary.
* `gamepad` (integer): *Read-only*. The zero-based gamepad ID.
